# Aplicación de tablas con JavaFX conectada a MariaDB

## Descripción

Aplicación desarrollada en Java utilizando JavaFX y FXML.

La aplicación permite gestionar una tabla de personas mediante una interfaz gráfica. Cada persona contiene un identificador, nombre, apellido y fecha de nacimiento.

Desde la interfaz se pueden añadir nuevas personas, seleccionar varias filas, eliminarlas y restaurar posteriormente los registros eliminados.
